# Avito Parser Pro (Node.js)

Этот парсер использует настоящий браузер (через Puppeteer) для сбора данных с Avito, что позволяет обходить базовые защиты от ботов.

## Установка

Убедитесь, что у вас установлен Node.js. Затем запустите установку зависимостей:

```bash
npm install
```

## Запуск

Запустите скрипт командой:

```bash
node parser.js
```

Или с указанием поискового запроса:

```bash
node parser.js "MacBook Pro"
```

## Как это работает
1. Скрипт открывает браузер Chrome.
2. Переходит на сайт Avito (Москва по умолчанию).
3. Ищет указанный товар.
4. Собирает данные (Заголовок, Цена, Ссылка).
5. Сохраняет результат в JSON файл.

**Внимание**: Для работы требуется стабильное интернет-соединение. Если Avito покажет капчу, вам может потребоваться решить её вручную в открывшемся окне браузера.
