# Client Release Copy Cleanup Design

**Date:** 2026-03-27

## Goal
Убрать из клиентского релиза все продающе-вредные надписи про возврат и все клиентски видимые упоминания `Смета 2007`, не ломая текущий document flow и не меняя интерфейс.

## Scope
- Вычистить надписи про возврат и `14 дней`, если они используются именно как маркетинговый текст или текст документа для клиента.
- Вычистить клиентски видимые упоминания `Смета 2007` в UI, документации, экспортируемых названиях документов, template labels и packaged resource names.
- Сохранить внутреннюю техническую совместимость там, где старые function/IPС names безопаснее оставить.

## Non-Goals
- Не переписывать licensing логику и не удалять сам trial-механизм, если пользователь просил убрать только надписи.
- Не делать большой рискованный рефакторинг внутренних API names без явной необходимости.

## Architecture
- Клиентски видимые строки чистятся в frontend и в desktop document generation.
- Поставочные resource names и имена шаблонов в `db` и `templates` переводятся на нейтральные коммерческие названия.
- Внутренние alias для совместимости могут быть оставлены, но итоговые названия в `.exe`, документах и generated files должны быть без `Смета 2007`.

## Validation
- Повторный `rg` по исходникам на `14 дней`, `возврат`, `Смета 2007`, `smeta2007`.
- `npm run build` во frontend.
- desktop node-tests для smoke-check после обновления resource names и document labels.
