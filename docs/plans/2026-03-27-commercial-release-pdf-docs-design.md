# Commercial Release PDF And Installer Assets Design

**Date:** 2026-03-27

## Goal
Закрыть пользовательскую ошибку при открытии сметы в PDF и режиме печати, не меняя интерфейс, и довести коммерческий desktop-релиз до клиентского уровня поставки: с руководством, стартовыми базами и сильной админ-документацией по лицензированию.

## Scope
- Исправить trusted desktop-path генерации PDF/печати для сметы.
- Оставить renderer и UI без редизайна и без изменения пользовательских сценариев.
- Улучшить installer-ресурсы для клиента: руководство, быстрый README и стартовые базы.
- Улучшить админскую документацию: выпуск лицензии, передача клиенту базы работ и материалов, поддержка и перенос лицензии.

## Architecture
- PDF/печать остаются в Electron main process. Вместо хрупкой загрузки HTML через `data:` URL используется более надёжный временный HTML-файл, который скрытое окно открывает локально перед `printToPDF`.
- Открытие созданных файлов остаётся через `shell.openPath`, но с явной обработкой ошибок, чтобы desktop-слой мог корректно сообщить о проблеме.
- Стартовые базы поставляются как отдельные клиентские артефакты внутри installer-ресурсов: `quick` и `full`, при этом полной базе отводится роль основной рекомендации.

## Constraints
- Интерфейс страниц сметы, активации и остальных экранов не менять.
- Новые зависимости не добавлять.
- Публичный IPC-контракт не ломать.

## Validation
- Узкие Node tests для PDF runtime helper и shell open-path handling.
- Существующие desktop tests должны остаться зелёными.
- После packaging/docs-итерации должен пройти `npm run build` там, где это уже используется для релизного smoke-check.
