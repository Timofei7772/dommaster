# Руководство пользователя SmetaAI

**Версия документа:** 2.0  
**Дата обновления:** 2026-03-27  
**Поддержка:** `@ZARU_Support`

## 1. Что входит в поставку

После установки у вас будут:
- приложение SmetaAI;
- руководство пользователя `getting_started.md`;
- быстрый файл `README.txt`;
- стартовые базы работ и материалов в папке `starter-db`.

## 2. Системные требования

- Windows 10/11 64-bit
- 4 GB RAM минимум
- 500 MB свободного места
- Интернет для активации лицензии

## 3. Установка

1. Запустите `SmetaAI_Setup_<версия>.exe`.
2. Выберите папку установки.
3. Дождитесь завершения установки.
4. Запустите SmetaAI через ярлык на рабочем столе или в меню Пуск.

## 4. Первый запуск

- При первом запуске программа инициализирует локальную базу данных.
- Встроенный полный каталог работ и материалов автоматически подхватывается из bundled ресурсов.
- Если полный каталог недоступен, программа использует резервный упрощённый вариант.

Для обычного старта вручную импортировать справочники не нужно: они уже входят в поставку.

## 5. Стартовые базы работ и материалов

В поставке лежат два варианта базы.

### Рекомендуемый вариант: `full`
- `catalog.json`
- `catalog_rsk.json`
- `regions.json`

Это основной рабочий набор для реального использования.

### Облегчённый вариант: `quick`
- `catalog_simple.json`

Подходит для обучения, тестовой установки и лёгкого стенда.

### Где искать файлы

После установки копии справочников находятся в:
- `resources\docs\client\starter-db\full`
- `resources\docs\client\starter-db\quick`
- `resources\starter-db\full`
- `resources\starter-db\quick`

Эти файлы удобно хранить как резервную копию или передавать между рабочими местами по инструкции администратора.

## 6. Активация лицензии

1. Откройте раздел `Лицензия`.
2. Введите ключ формата `ZARU-XXXX-XXXX-XXXX-XXXX`.
3. Подтвердите активацию на текущем компьютере.
4. Дождитесь ответа сервера.
5. После успешной активации программа сохранит локальный защищённый кэш лицензии.

## 8. Важно о лицензии

- Лицензия привязывается к конкретному компьютеру.
- Один слот нельзя использовать одновременно на двух разных устройствах.
- Для переноса лицензии нужно освободить слот в разделе лицензии или обратиться в `@ZARU_Support`.
- Без интернета программа может работать по ранее подтверждённой лицензии до 7 дней.

## 9. Демо-режим

Без лицензии доступны:
- до 3 смет;
- до 5 AI-запросов;
- экспорт Excel.

В демо-режиме:
- экспорт сметы в PDF недоступен;
- печать через защищённый PDF-поток недоступна;
- ограничения снимаются только после активации лицензии.

## 10. Экспорт сметы в PDF и печать

### Экспорт в PDF

1. Откройте нужную смету.
2. Нажмите кнопку `PDF`.
3. Программа создаст PDF-файл в рабочей папке сметы.
4. Готовый файл откроется системным приложением Windows для PDF.

### Печать

1. Откройте нужную смету.
2. Нажмите кнопку `Печать`.
3. Программа подготовит PDF для печати.
4. Откройте файл и распечатайте его через привычный PDF-просмотрщик.

### Если PDF не открылся

Проверьте:
- установлен ли в Windows просмотрщик PDF;
- не блокирует ли запуск корпоративная политика безопасности;
- доступна ли папка, куда сохраняется смета.

Если проблема повторяется, отправьте в поддержку:
- номер лицензии;
- версию SmetaAI;
- скриншот ошибки;
- номер или название сметы.
