# Starter DB для клиента

Эта папка входит в поставку SmetaAI вместе с установщиком и содержит копии справочников работ и материалов.

## Что внутри

### `quick`
- `catalog_simple.json`

Подходит для быстрого старта, обучения и лёгких стендов.

### `full`
- `catalog.json`
- `catalog_rsk.json`
- `regions.json`

Это основной рекомендованный набор для рабочего использования.

## Как SmetaAI использует эти данные
- При первом запуске desktop-приложение автоматически загружает встроенный справочник из папки `resources\db`.
- Для рабочего старта используется полный каталог, если он доступен.
- Файлы из `starter-db` нужны как удобная копия для передачи клиенту, резервного хранения и повторной выдачи.

## Что передавать клиенту
- Всегда передавайте полную базу `full` как основной вариант.
- `quick` оставляйте как облегчённый резервный набор.

## Где искать после установки
- Руководство клиента: `resources\docs\client\getting_started.md`
- Быстрый README: `resources\docs\client\README.txt`
- Копии стартовых баз: `resources\docs\client\starter-db\...`
- Дополнительная копия starter-db: `resources\starter-db\...`

## Поддержка
Если клиенту нужно повторно выдать справочники или уточнить, какой набор использовать, направляйте его в `@ZARU_Support`.
