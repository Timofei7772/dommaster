# Генерация лицензионных ключей ZARU Смета

## Обзор системы лицензирования

ZARU Смета использует надёжную систему защиты на основе:
- **AES-256-GCM** шифрования для защиты ключей
- **HWID** привязки к оборудованию компьютера
- **Криптографической подписи** для проверки подлинности

## Формат лицензионного ключа

```
ZARU-XXXX-XXXX-XXXX-XXXX
```

Пример: `ZARU-AB12-CD34-EF56-GH78`

## Как генерировать ключи (для администратора)

### 1. Запуск генератора ключей

```bash
cd desktop
node generate-license.js
```

### 2. Параметры генерации

| Параметр | Описание | Пример |
|----------|----------|--------|
| `type` | Тип лицензии | `personal`, `business`, `enterprise` |
| `expires` | Срок действия | `2025-12-31` или `unlimited` |
| `features` | Доступные функции | `all`, `basic`, `pro` |
| `hwid` | ID оборудования | Получается автоматически |

### 3. Пример скрипта генерации

```javascript
const { generateLicense } = require('./license-secure.js')

// Генерация персональной лицензии на 1 год
const key = generateLicense({
  type: 'personal',
  expires: new Date(Date.now() + 365 * 24 * 60 * 60 * 1000),
  features: 'all',
  maxDevices: 1
})

console.log('Ваш ключ:', key)
// Вывод: ZARU-XXXX-XXXX-XXXX-XXXX
```

## Активация на устройстве пользователя

1. Пользователь открывает приложение
2. Переходит в **Настройки → Активация**
3. Вводит лицензионный ключ
4. Система:
   - Проверяет формат ключа
   - Дешифрует данные
   - Сверяет HWID
   - Проверяет срок действия
5. При успехе — активирует функционал

## Безопасность

### Что защищено:
- ✅ Ключи зашифрованы AES-256-GCM
- ✅ Привязка к железу (HWID)
- ✅ Криптографическая подпись
- ✅ Обфускация кода генератора

### Что НЕ делать:
- ❌ Не публиковать `SECRET_KEY` в открытом доступе
- ❌ Не хранить ключи в git репозитории
- ❌ Не давать доступ к генератору посторонним

## Отзыв лицензии

Если нужно заблокировать ключ:

1. Добавьте ключ в файл `revoked-keys.json`
2. При следующей проверке ключ будет отклонён

```json
{
  "revoked": [
    "ZARU-AB12-CD34-EF56-GH78"
  ]
}
```

## Онлайн-верификация (опционально)

Для дополнительной защиты можно добавить проверку через сервер:

```javascript
// В будущем можно добавить
const isValid = await verifyOnline(licenseKey)
```

Это позволит:
- Централизованно управлять лицензиями
