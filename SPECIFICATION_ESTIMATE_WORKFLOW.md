# 📋 ПОЛНАЯ СПЕЦИФИКАЦИЯ WORKFLOW ЗАПОЛНЕНИЯ СМЕТЫ

## 🎯 ЧАСТЬ 1: АРХИТЕКТУРА РАСЧЕТА СМЕТЫ

### 1.1 Структура данных позиции

```javascript
interface EstimateItem {
  // Основной данные
  id: number
  estimate_id: number
  section_id?: number            // Раздел сметы (опционально)
  
  // Описание работы
  code: string                   // Код работы (МДС, СМЕТА 2007)
  name: string                  // Наименование работы
  unit: string                  // Единица измерения (м², м, т, шт, день и т.д.)
  quantity: number              // Количество (основная метрика)
  
  // ЦЕНЫ И СТОИМОСТИ (базовые - до коэффициентов)
  material_price: number        // Цена материалов за единицу (руб/ед)
  labor_price: number           // Цена работы за единицу (руб/ед)
  base_price: number            // Базовая цена за ед (material + labor)
  
  // ФАКИЧЕСКИЕ ЦЕНЫ (с коэффициентами)
  material_total: number        // material_price × quantity
  labor_total: number           // labor_price × quantity
  total: number                 // material_total + labor_total (ПОДИТОГ БЕЗ НДС)
  
  // КОЭФФИЦИЕНТЫ И НАДБАВКИ (применяются КО ВСЕЙ СМЕТЕ)
  // ⚠️ ВАЖНО: коэффициенты хранятся на уровне сметы, не позиции!
  // Но показываем их в позиции для справки:
  material_coef?: number        // К материалам (например 1.04 = +4%)
  work_coef?: number            // К работам (например 1.8 = +80%)
  
  // ПРОМЕЖУТОЧНЫЕ РАСЧЕТЫ (вычисленные)
  subtotal: number              // material_total + labor_total
  overhead_amount?: number      // (subtotal × overhead%) из сметы
  profit_amount?: number        // ((subtotal + overhead) × profit%) из сметы
  vat_cost?: number             // (subtotal + overhead + profit) × vat)
  total_with_vat?: number       // subtotal + overhead + profit + vat
  
  // ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ
  sort_order: number            // Порядок в разделе
  created_at: string            // Дата создания
  updated_at: string            // Дата обновления
}
```

### 1.2 Структура данных сметы

```javascript
interface Estimate {
  id: number
  project_id?: number
  name: string                  // Наименование сметы
  number: string               // Номер сметы
  description?: string
  
  // БАЗОВЫЕ СУММЫ (считаются из позиций)
  total_materials: number      // SUM(item.material_total) для всех позиций
  total_labor: number          // SUM(item.labor_total) для всех позиций
  subtotal: number             // total_materials + total_labor (БЕЗ НДС И НАДБАВОК)
  
  // КОЭФФИЦИЕНТЫ СМЕТЫ (применяются ко ВСЕЙ СМЕТЕ)
  material_coef: number        // базово 1.04 (к материалам)
  work_coef: number            // базово 1.8 (к работам)
  
  // С КОЭФФИЦИЕНТАМИ
  materials_with_coef: number  // total_materials × material_coef
  labor_with_coef: number      // total_labor × work_coef
  subtotal_with_coef: number   // materials_with_coef + labor_with_coef
  
  // НАДБАВКИ
  overhead_percent: number     // % надбавки на ООН (обычно 16-19%)
  overhead_amount: number      // subtotal_with_coef × overhead_percent
  
  profit_percent: number       // % прибыли подрядчика (обычно 15-20%)
  profit_amount: number        // (subtotal_with_coef + overhead) × profit_percent
  
  // НАЛОГ
  vat_percent: number          // 20%, 10%, 0% (по умолчанию 20)
  vat_enabled: boolean         // Налогообложение
  vat_cost: number             // (subtotal_with_coef + overhead + profit) × vat_percent
  
  // ИТОГОВЫЕ СУММЫ
  total_cost: number           // БЕЗ НДС = subtotal_with_coef + overhead + profit
  total_with_vat: number       // С НДС = total_cost + vat_cost
  
  // СТАТУС
  status: string               // draft, approved, completed
  created_at: string
  updated_at: string
}
```

## 🔢 ЧАСТЬ 2: ФОРМУЛЫ РАСЧЕТОВ (ПРАВИЛЬНЫЕ)

### 2.1 Расчет на уровне ПОЗИЦИИ

```
1. Материалы по позиции:
   material_total = material_price × quantity

2. Работы по позиции:
   labor_total = labor_price × quantity

3. Подитог позиции (БЕЗ коэффициентов и надбавок):
   position_subtotal = material_total + labor_total
```

### 2.2 Расчет на уровне СМЕТЫ

#### ШАГ 1: Суммирование по позициям (без коэффициентов)
```
total_materials = SUM(material_total) для всех positions
total_labor = SUM(labor_total) для всех positions
subtotal = total_materials + total_labor
```

#### ШАГ 2: Применение коэффициентов сметы
```
⚠️ ВАЖНО: Коэффициенты умножают (не складывают)!

materials_with_coef = total_materials × material_coef
  Пример: 100,000 × 1.04 = 104,000

labor_with_coef = total_labor × work_coef
  Пример: 500,000 × 1.8 = 900,000

subtotal_with_coef = materials_with_coef + labor_with_coef
  = 104,000 + 900,000 = 1,004,000
```

#### ШАГ 3: Надбавка на ООН (Накладные расходы)
```
overhead_amount = subtotal_with_coef × (overhead_percent / 100)
  
Пример (16% надбавка):
  = 1,004,000 × 0.16 = 160,640
```

#### ШАГ 4: Прибыль подрядчика
```
profit_amount = (subtotal_with_coef + overhead_amount) × (profit_percent / 100)

Пример (20% прибыли):
  = (1,004,000 + 160,640) × 0.20 = 232,928
```

#### ШАГ 5: НДС (Налог на добавленную стоимость)
```
⚠️ НДС считается от СУММЫ БЕЗ НДС:

amount_before_vat = subtotal_with_coef + overhead_amount + profit_amount
                  = 1,004,000 + 160,640 + 232,928 = 1,397,568

vat_cost = amount_before_vat × (vat_percent / 100)

Пример (20% НДС):
  = 1,397,568 × 0.20 = 279,514

⚠️ НЕПРАВИЛЬНО: НДС от суммы с НДС (круговая)
   ПРАВИЛЬНО: НДС от суммы БЕЗ НДС
```

#### ШАГ 6: Итоговые суммы
```
total_cost = amount_before_vat
           = 1,397,568 руб (БЕЗ НДС)

total_with_vat = total_cost + vat_cost
               = 1,397,568 + 279,514 = 1,677,082 руб (С НДС)
```

## 📄 ЧАСТЬ 3: ЗАПОЛНЕНИЕ ДОКУМЕНТОВ

### 3.1 КС-2 (Акт о приёмке выполненных работ)

**Когда используется:** Во время выполнения работ, при приёмке каждого этапа

**Что заполняется автоматически:**
```
Шапка:
✅ Номер КС-2 (из базы)
✅ Дата (текущая дата)
✅ Номер договора (из сметы/проекта)
✅ Наименование объекта (из проекта)
✅ ФИО прораба (из настроек/договора)

Позиции (из основной сметы):
✅ Список работ по разделам
✅ Выполненный объем (вводит прораб% или кол-во)
✅ Сметная цена за единицу
✅ Стоимость выполненного объема (расчет)

Итоги:
✅ Сумма КС-2 (БЕЗ НДС)
✅ НДС (пересчет)
✅ Сумма с НДС

Подписи:
✅ От заказчика (поле для подписи)
✅ От подрядчика (автоматически ФИО прораба)
```

### 3.2 КС-3 (Справка о стоимости работ)

**Когда используется:** Для документирования стоимости работ (справка на получение)

**Что заполняется автоматически:**
```
Все данные из ОСНОВНОЙ СМЕТЫ:
✅ Номер и дата сметы
✅ Полный список работ с ценами
✅ Разделы (если есть)
✅ Все подитоги и проценты
✅ Информация об НДС
✅ Итоговые суммы

Реквизиты:
✅ ФИО и подпись (из настроек)
✅ Дата подписания (текущая)
✅ Печать (опционально)
```

### 3.3 М-29 (Ведомость расхода материалов)

**Когда используется:** При отпуске материалов на объект

**Что заполняется автоматически:**
```
Из позиций сметы, где есть материалы:
✅ Материалы (берутся из разложения работ)
✅ Количество (рассчитывается: material_qty × work_quantity)
✅ Единица измерения
✅ Цена за единицу
✅ Сумма

Пример:
  Работа: "Укладка плитки" - 100 м², 50 руб/м² плитка + 30 руб/м² клей
  → М-29: 100 м² плитки, 100 м² клея (с расценками)

Подписи:
✅ Материально ответственное лицо
✅ Получатель
```

### 3.4 Дефектовка (Список дефектов/доделок)

**Когда используется:** При обнаружении дефектов при приёмке

**Что предзаполняется:**
```
Список работ из ОСНОВНОЙ СМЕТЫ (для удобства заполнения):
✅ Наименование работ
✅ Разделы
✅ Смета цены (для справки)

Что вводит пользователь:
⚙️ Какая работа имеет дефект
⚙️ Описание дефекта
⚙️ Объем доделок (% или кол-во)

```

### 3.5 ФОТ (Ведомость фонда оплаты труда)

**Когда используется:** Для учёта зарплаты рабочих

**Что автоматически:**
```
Из СМЕТЫ (labor_with_coef):

Что вводит пользователь:
⚙️ ФИО рабочего
```

### 5.1 Обязательные правила

```javascript
// При добавлении позиции:
```

```
При ЛЮБОМ изменении позиции или сметы:
1. Пересчитываются суммы позиций
2. Пересчитываются итоги по смете
3. Пересчитываются коэффициенты
4. Пересчитываются налоги
5. Обновляется предпросмотр в UI
6. Документы становятся готовыми к печати
```

## 📊 ЧАСТЬ 6: ИНТЕГРАЦИЯ С ДОКУМЕНТАМИ

### 6.1 Блок-схема потоков данных

```
ОСНОВНАЯ СМЕТА (источник истины)
    ↓
    ├→ КС-2 (выполненный объем) [заполняется во время работ]
    ├→ КС-3 (справка) [печатается один раз]
    ├→ М-29 (материалы) [вводятся материалы из смет позиций]
    ├→ ФОТ (зарплата) [вводятся рабочие, считаются суммы]
    ├→ Дефектовка [предзаполняется список работ]
    ├→ Смета 2007 [экспортируется в формат СМЕТА 2007]
    └→ Счёт-фактура [выставляется заказчику]
```

### 6.2 Синхронизация при изменении сметы

```
Если пользователь изменил основную смету:
⚠️ КС-2 - нужно пересчитать (выполненный % меняет сумму)
⚠️ КС-3 - должна загруститься заново
⚠️ М-29 - останется с исходными материалами
⚠️ ФОТ - останется с исходными рабочими
✅ Счёт - пересчитается автоматически
✅ Дефектовка - предложить пересчитать
```

## 🚀 ЧАСТЬ 7: РЕАЛИЗАЦИЯ (В КОДЕ)

### 7.1 Правильный порядок заполнения в EstimateDetail

```
1. Пользователь открывает смету
2. Видит список текущих позиций
3. Может:
   a) Добавить новую позицию (вручную или из каталога)
   b) Редактировать существующую
   c) Удалить позицию
4. При каждом изменении пересчитываются итоги
5. После заполнения может распечатать документы:
   - КС-3 (из основной сметы)
   - Смету в Excel/PDF
   - Счёт-фактуру
```

### 7.2 Правильная функция recalculate

```javascript
function recalculateEstimate(estimateId) {
    const estimate = getEstimate(estimateId)
    const items = getEstimateItems(estimateId)
    
    // ШАГ 1: Суммы по позициям
    let total_materials = 0
    let total_labor = 0
    
    for (const item of items) {
        total_materials += (item.material_price || 0) * item.quantity
        total_labor += (item.labor_price || 0) * item.quantity
    }
    
    const subtotal = total_materials + total_labor
    
    // ШАГ 2: С коэффициентами
    const material_coef = estimate.material_coef || 1.04
    const work_coef = estimate.work_coef || 1.8
    
    const materials_with_coef = total_materials * material_coef
    const labor_with_coef = total_labor * work_coef
    const subtotal_with_coef = materials_with_coef + labor_with_coef
    
    // ШАГ 3: Накладные
    const overhead_percent = estimate.overhead_percent || 0.16
    const overhead_amount = subtotal_with_coef * overhead_percent
    
    // ШАГ 4: Прибыль
    const profit_percent = estimate.profit_percent || 0.20
    const profit_amount = (subtotal_with_coef + overhead_amount) * profit_percent
    
    // ШАГ 5: НДС
    const amount_before_vat = subtotal_with_coef + overhead_amount + profit_amount
    const vat_enabled = estimate.vat_enabled !== false
    const vat_percent = vat_enabled ? (estimate.vat_percent || 20) / 100 : 0
    const vat_cost = amount_before_vat * vat_percent
    
    // ШАГ 6: Итоги
    const total_cost = amount_before_vat
    const total_with_vat = total_cost + vat_cost
    
    // Обновляем смету
    db.run(`UPDATE estimates SET
        total_materials = ?,
        total_labor = ?,
        subtotal = ?,
        overhead_amount = ?,
        profit_amount = ?,
        vat_cost = ?,
        total_cost = ?,
        total_with_vat = ?
    WHERE id = ?`, [
        total_materials,
        total_labor,
        subtotal,
        overhead_amount,
        profit_amount,
        vat_cost,
        total_cost,
        total_with_vat,
        estimateId
    ])
    
    return { total_cost, total_with_vat }
}
```

```
□ Позиции имеют название, единицу, количество
```

## 🎓 ЗАКЛЮЧЕНИЕ

**Ключевые моменты:**
1. **Коэффициенты УМНОЖАЮТСЯ**, не складываются
2. **НДС считается** от суммы БЕЗ НДС
3. **Все документы** питаются из ОДНОЙ ОСНОВНОЙ СМЕТЫ
4. **Автоматический расчёт** при каждом изменении
5. **Валидация** на каждом шаге заполнения

Эта спецификация обеспечит профессиональную работу приложения без ошибок в расчётах! ✅
