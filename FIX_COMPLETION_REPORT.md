## 🔴 Проблемы решены

### Ошибка #1: ReferenceError при инициализации ipcMain
**Критическая ошибка при запуске упакованного приложения:**
```
ReferenceError: Cannot access 'ipcMain' before initialization
```

**Корневая причина**: sql.js требовалась синхронно на глобальном уровне  
**Решение**: Переместить require внутрь async функции  
**Статус**: ✅ ИСПРАВЛЕНО

---

### Ошибка #2: ReferenceError - recalculateEstimateWithCoefficients не определена
**Вторая ошибка при запуске:**
```
ReferenceError: recalculateEstimateWithCoefficients is not defined
at Object.<anonymous> (main.js:1446:60)
```

**Корневая причина**: Функция была удалена из database.js но оставалась в экспорте и использовании  
**Решение**: Заменить все вызовы на `recalculateEstimate`  
**Статус**: ✅ ИСПРАВЛЕНО
